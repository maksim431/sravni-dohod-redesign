# Сравни доход — концепт редизайна

Интерактивный прототип редизайна раздела «Сравни доход» Telegram mini-app для курьеров. Сделан как тестовое задание.

**Живой прототип:** https://maksim431.github.io/sravni-dohod-redesign/

Что можно попробовать:
- первый запуск: выбрать режим (пешком / вело / авто) и свои сервисы;
- главная: лидер прямо сейчас, ставки всех сервисов, фильтр «Все / Мои», лучшие окна недели, тепловая карта по часам;
- тап по сервису: шторка с графиком дня, прогнозом диапазоном и напоминанием перед пиком;
- режим «Авто»: пустое состояние со сбором данных;
- кнопка «+»: добавить доход и сразу увидеть ₽/ч.

Дизайн: Максим Кощеев, UX/UI и продуктовый дизайнер · [uxuidesign.ru](https://uxuidesign.ru)

Концепт не связан с компаниями-сервисами доставки. Все данные и ставки вымышлены, логотипы заменены буквами.
